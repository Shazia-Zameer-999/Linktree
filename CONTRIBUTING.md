# Contributing

Thanks for helping improve Linktree Clone.

## Local setup

1. Fork and clone the repository.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and add a development MongoDB URI.
4. Run `npm run dev`.

## Before opening a pull request

1. Create a focused branch such as `feature/profile-themes` or `fix/handle-validation`.
2. Keep credentials and `.env.local` out of commits.
3. Run `npm run lint` and `npm run build`.
4. Explain the behavior change and include screenshots for visual work.

Use clear commit messages; Conventional Commit prefixes such as `feat:`, `fix:`, and `docs:` are encouraged.
