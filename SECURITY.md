# Security policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Report them privately through GitHub's **Security → Report a vulnerability** flow when private vulnerability reporting is enabled for this repository. Include reproduction steps, affected routes, and the potential impact without including real user data or credentials.

Never commit MongoDB connection strings, access tokens, or copies of `.env.local`.

## Supported version

Security fixes are applied to the latest version on the `main` branch.
